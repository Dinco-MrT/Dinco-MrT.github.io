# Dinco-MrT.github.io

Web apps and games for Meta Ray-Ban Display glasses, one folder per app.
Built in `~/Developer/RayBanDisplay/apps/<name>/` and published with `scripts/deploy-pages.sh <name>`.

- [Lane Runner](https://dinco-mrt.github.io/lane-runner/) — Vapor Freeway: vaporwave freeway racer with lanes you pave and close, trucks to ride, power-ups
