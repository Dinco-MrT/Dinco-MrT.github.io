# Dinco-MrT.github.io

Web apps and games for Meta Ray-Ban Display glasses, one folder per app.
Built in `~/Developer/RayBanDisplay/apps/<name>/` and published with `scripts/deploy-pages.sh <name>`.

- [Lane Runner](https://dinco-mrt.github.io/lane-runner/) — Vapor Freeway: vaporwave freeway racer; lanes open and end, boost, ride the car carriers
- [Ramp Rivals](https://dinco-mrt.github.io/ramp-rivals/) — neon grid racing: race seven rival bots over eight lanes; bump, draft, boost and trick off ramps
